# Lakekeeper Go Client

Go Client for [Lakekeeper API](https://docs.lakekeeper.io).

It provides a convenient way to interact with Lakekeeper services from your Go applications (And a new CLI tool in preview).

## Disclaimer

This repository is no longer actively maintained. Development has moved to [lakekeeper/go-lakekeeper](https://github.com/lakekeeper/go-lakekeeper), which is the official fork and the recommended place to follow the project.
